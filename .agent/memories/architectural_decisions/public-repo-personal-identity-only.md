# Public repo: personal identity only

ZeroGFileMan is public (MIT). Commit only with the maintainer's personal identity: check the repo-local `git config user.email` before committing. Keep LAN IPs, model hashes and absolute home paths out of committed files; use localhost / placeholders. Pre-public history lives in private archived HappyMonkeyAI/ZeroGFileMan-archive.
