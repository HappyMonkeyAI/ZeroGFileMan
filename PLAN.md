# PLAN — MVP for user testing

## Goal

Testable ZeroG FileMan MVP: dual-pane + breadcrumbs + CRUD + cross-pane paste + dual jewels with shallow fuzzy navigate and action commands.

## Done when

- [x] Doc spine + ADRs
- [x] Dual-pane browse + breadcrumbs + favorites
- [x] CRUD toolbar + copy/cut/paste
- [x] Navigate jewel with depth-2 fuzzy + Auto-nav
- [x] Action jewel command map
- [x] `npm run typecheck && npm test && npm run build` green
- [x] `npm start` launches the MVP for manual exercise

## Out of scope this MVP

Builtin Whisper worker, 4-pane layout engine, packaging, SFTP.
